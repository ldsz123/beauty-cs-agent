客户问答效果

客户咨询 → 智能路由 → 知识检索 → 业务查询 → 人工接待

  • 混合检索：关键词 + 向量 + 重排，带知识来源
  • 业务查询：订单 / 物流 / 库存 / 退款
  • 人工接待：转人工、客服接管、会话回复

技术架构

FastAPI + 三级流水线 + 混合检索 + 可观测性
  • FastAPI 异步服务 + 中间件体系
  • 三级处理流水线（可合并为单次调用）
  • LongCat 大模型（OpenAI 兼容）
  • 内存 / PostgreSQL / Redis 三模式存储
  • Prometheus 指标 + 结构化日志
  • 275 个自动化测试 + CI
